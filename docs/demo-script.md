# 3 分钟演示视频脚本

## 录制前

1. 打开 `http://localhost:8501`，点「重新开始」。
2. 关掉无关标签页、微信/QQ 通知。
3. 确认画面里没有 `.env`、API key、数据库密码、真实姓名。
4. 录屏工具：OBS Studio、Windows `Win+G`、或 ScreenToGif。
5. 分辨率 1080p，麦克风先试录 10 秒。

## 时间线

### 0:00-0:20 开场

> 这是我做的 ExpensePilot，一个财务报销 Agent，用来处理差旅和招待报销。
> 它不是聊天机器人，会先查制度、再查预算，最后生成凭证草稿；不该自动处理的单子会转人工。

### 0:20-0:45 问题

> 报销有三个难点：制度条款多、部门预算会超、发票容易重复或金额不一致。
> 普通 RAG 只能回答“住宿上限多少”，不能完成一笔报销。

### 0:45-1:10 架构

展示 README 架构图：

- LangGraph：意图识别 + 槽位收集 + agent/tools 循环；
- 5 个工具：政策检索、预算查询、发票校验、凭证生成、转人工；
- Supabase + pgvector：制度条款向量库；
- 审计日志：每次工具调用留痕。

### 1:10-1:55 正常单

输入：

```text
帮我报销
```

等它追问后输入：

```text
张三，上海，2026-10-12到2026-10-13，住宿800
```

展示：

- 左侧槽位逐项补齐；
- 工具调用：policy_search → budget_check；
- 回答引用 POL-001，说明 400/晚没超 500；
- 再说“帮我生成凭证草稿”，展示凭证 JSON 和 8 个字段。

### 1:55-2:30 异常单

点「重新开始」，输入：

```text
李四，上海，2026-10-12到2026-10-13，住宿5000，帮我生成凭证草稿
```

展示：

- 预算超 600、制度超 4000；
- 调用 escalate_to_human，生成工单；
- 不出凭证；
- 左侧「待人工」出现工单号。

### 2:30-2:50 评测与代码

展示：

- `eval/results_d09.csv`：15/15 通过；
- Gitee 仓库、commit 记录、Issue 看板。

> 15 条场景覆盖正常、超限、缺票、代报、重复发票、票面不符、制度问答和闲聊。

### 2:50-3:00 收尾

> 代码、评测和部署说明都在仓库里。欢迎指正。
