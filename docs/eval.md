# 评测方案

## 指标

| 指标 | 定义 | 目标 |
|---|---|---|
| 任务完成率 | 端到端正确完成 / 总数 | ≥85% |
| 工具序列准确率 | 期望工具集合与实际一致 | ≥90% |
| 凭证字段完整率 | 8 个必填字段齐全 | ≥95% |
| 超限 / 越权拦截率 | 该转人工的全部转人工 | 100% |
| RAG 引用命中率 | top-3 含正确条款 | ≥90% |
| P95 时延 | 单轮端到端 | ≤3s |

## 场景分布（30 条）

| 类型 | 条数 | 说明 |
|---|---|---|
| 正常报销 | 10 | 单城市 / 多城市，交通 / 住宿 / 餐饮 |
| 超限 / 超标 | 5 | 住宿、餐补、交通工具 |
| 缺票 / 票面不符 | 4 | 无票、抬头错、金额不一致 |
| 模糊 / 多轮 | 4 | 缺城市 / 天数 / 费用类型 |
| 越权 / 敏感 | 3 | 代报、重复报销、虚假发票 |
| 制度问答 | 4 | 纯知识查询 |
